# Translations (i18n)

Medieval Tetris ships in **six languages**:

| Code | Language |
| --- | --- |
| `en` | English |
| `es` | Español |
| `fr` | Français |
| `de` | Deutsch |
| `it` | Italiano |
| `pt` | Português |

## How it works

- `js/i18n.js` detects the language on first visit
  (`localStorage` → `navigator.languages` → `es`), exposes
  `MT_I18n.t(key, vars)` and re-renders everything marked in the DOM.
- Static strings use attributes:

  ```html
  <span data-i18n="hold">Reserva</span>
  <button data-i18n-title="pause">⏸</button>
  ```

- Dynamic strings are translated in JS with `{placeholders}`:

  ```js
  t('goalLabel', { n: 12 })   // "Clear 12 lines" / "Limpiar 12 líneas"
  ```

- Switching language (`MT_I18n.set('fr')`) updates the DOM, the HUD, the
  level-select grid, the how-to text and any open banner immediately, and is
  remembered in `localStorage`.

## File layout

```js
// js/locales/fr.js
(function (g) {
  'use strict';
  g.MT_Locales = g.MT_Locales || {};
  g.MT_Locales.fr = {
    __name: 'Français',
    __dir: 'ltr',
    brand: 'Medieval Tetris',   // product name stays in English
    tagline: '1000 niveaux du très facile au très difficile',
    // … 79 keys, identical names and order to en.js
    worldLink: 'de',
    worldNoun: [ /* 10 realms */ ],
    worldQual: [ /* 10 elements */ ],
    tiers:     [ /* 10 ranks  */ ]
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

## Rules

1. **Same keys, same order** as `js/locales/en.js` — no extras, no omissions.
2. **Never touch placeholders** (`{n}`, `{score}`, `{lines}`, `{points}`, …) —
   the test compares them key by key against English.
3. **HTML stays intact** inside `howto` — only the human text is translated.
4. **World-name grammar**: `worldNoun + worldLink + worldQual` must read
   naturally in the target language.
   - `en` "Kingdom of Fire" · `es` "Reino de Fuego" · `fr` "Royaume de Feu"
   - `it` uses `di` (gender-neutral): "Regno di Fuoco"
   - `de` uses the genitive `des`, so every `worldQual` must be masculine or
     neuter: "Reich des Feuers"
5. **`tiers` and `mod_*` labels** are game terminology — use the community
   Tetris vocabulary of that language (e.g. *Tetris / Tetris / Tetris*,
   *hold / reserva / Riserva / réserve*).

## Adding a language (3 steps)

1. Copy `js/locales/en.js` to `js/locales/<code>.js`, rename the object to
   `MT_Locales.<code>` and translate the values.
2. Add `<script src="js/locales/<code>.js"></script>` in `index.html`.
3. Register it in `js/i18n.js` (`SUPPORTED` + `LABELS`) and run `npm test` —
   the suite checks key parity, placeholders, world-name uniqueness and that
   every UI key used by `index.html` and `main.js` exists in the new locale.
